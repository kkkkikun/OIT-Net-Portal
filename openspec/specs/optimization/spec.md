# Optimization Spec — oit-portal

> 版本: 1.0.0 | 最后更新: 2026-10-16

## Purpose

记录项目中的优化点与技术债务，持续改进代码质量。条目过多时由 openspec-archivist 清理。

## Requirements

### Requirement: 优化点记录

发现的性能瓶颈、代码异味、技术债务 MUST 记录：问题 / 当前影响 / 建议方案 / 优先级。

#### Scenario: 发现优化机会

- **WHEN** 发现可优化点
- **THEN** 追加到下方表格，标注优先级（高/中/低）

#### Scenario: 完成优化

- **WHEN** 完成某项优化
- **THEN** 标记完成日期与实际效果，不移除历史记录

### Requirement: 优化优先级

优化 MUST 按优先级处理，高优先级 SHALL 优先，不与小修小补混杂。

#### Scenario: 规划迭代

- **WHEN** 安排优化工作
- **THEN** 按优先级排序，先处理影响认证可靠性、安全性、双端稳定性的条目
